# Testing Synapse on another machine

## What to copy

Just this one file:

```
synapse-ai-cli-0.1.0.tgz
```

Everything is bundled inside — server, dashboard, hooks, CLI.

## Requirements

- Node.js 20+

## Install and run

```bash
cd ~/your-project
npx ./synapse-ai-cli-0.1.0.tgz start
```

## Uninstall

Nothing to uninstall — npx leaves no trace.
