Concept 03

Graph Zoom + Pulse

When a notification arrives, the graph smoothly zooms to the relevant node, dims the rest, and pulses an attention ring with the notification message floating above.

Concept 04

Lens Notification Cards

Cards slide up from the bottom of the lens panel like post-it notes. Each shows session context and an action button to jump to the blocked node. Dismissable individually.

Concept 05

VS Code Pit Board

Native VS Code integration — status bar shows session counts, tree view badges highlight blocked sessions, and toast notifications surface with action buttons.
