Conversation Threading Prototypes

Four approaches to evolving Synapse from "session + disconnected prompts" to "session + threaded conversation." Now with multi-response segments — one prompt can trigger multiple response segments interleaved with tool calls.

A: Chat Lane— vertical thread, tools inside responses
B: Turn Cards— prompt + response as one unit
C: Dual Timeline— prompts left, responses right
D: Node Graph— extends React Flow with response nodes
Approach A — Threaded Chat Lane
Familiar chat UX. The hybrid multi-response pattern: the final response text is always visible. Click "3 reasoning steps" to expand the intermediate segments that led to it. 1 prompt → N text segments interleaved with tools → 1 final answer. Collapsed by default = low noise. Expand = full reasoning chain.

Approach B — Turn Cards with Segment Timeline
Each turn is a card. Collapsed: you see prompt summary on the left, final response on the right. Expanded: a vertical timeline showing every segment and tool call in order. The "process" becomes a playback-style timeline inside the card. Multi-response pattern: the expanded detail shows a step-by-step timeline of text segments interleaved with tool calls. Each step has a dot marker — blue for text, purple for tools.

Approach D — Node Graph with Multi-Response
Builds on the existing React Flow graph. New Response node type (blue). For multi-response turns, the response node shows the final text but has a "3 segments" badge. Click to expand into a stacked chain: Response 1 → tools → Response 2 → tools → Response 3 (final). Collapsed by default for clean graphs. The graph chain becomes: Session → Prompt → Response[final] → [Tools, Agents]. Expand a multi-segment response to see: Prompt → Resp 1 → Resp 2 → Resp 3[final] → [Tools, Agents].
Multi-response in the graph (Turn 3 above):
• Collapsed (default): Prompt → Response (final text, "3 segments" badge) → Tools/Agents
• Expanded: Prompt → Seg 1 (dim, dashed) → Seg 2 (dim, dashed) → Response (final, bright) → Tools/Agents
• Intermediate segments are dashed-border, dimmed nodes — clearly "work in progress"
• Each intermediate segment shows its tool calls inline as small text
• Click the "3 segments" badge on the final response to toggle expansion

Weakness Long sessions scroll Less conversational feel Complex to implement Graph gets wider
