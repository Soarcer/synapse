# Synapse — Video Script (voiceover)

> Timing is approximate. Match to your existing footage cuts.
> Text overlays are in **[brackets]**. Voiceover is plain text.
> Tone: calm, direct, slightly dry. Like explaining something cool to a friend who codes.

---

## INTRO (0:00–0:05)

**[Synapse]**

Claude Code does a lot behind a blinking cursor. Synapse lets you see it all.

---

## THE GRAPH (0:05–0:15)

**[Watch Claude work]**

Every action Claude takes shows up as a node in a live graph. Sessions at the top, your prompts below with Claude's responses, agents and tool calls branching out to the side. The tree builds itself as you watch.

---

## NODE TYPES (0:15–0:22)

**[All actions visualized as nodes]**

Nodes are color-coded by status. Green for complete, blue for running, orange for waiting on approval. You can see at a glance what's active, what's done, and what's stuck.

---

## INSPECTOR (0:22–0:30)

**[Node inspector]**

Click any node and the inspector opens with full detail. Tool arguments, response payloads, token counts, timing. Each node type shows different properties — a tool call looks different from an agent spawn, because it is.

---

## LENSES — TREEMAP (0:30–0:36)

**[Treemap lens]**

The treemap sizes each block by tokens, duration, or activity count. One glance tells you where the time and money are going.

---

## LENSES — COMPACTION (0:36–0:40)

**[Compaction lens]**

The compaction timeline tracks context window pressure. When Claude forgets something you told it ten minutes ago, this is where you find out why.

---

## LENSES — SANKEY (0:40–0:44)

**[Sankey lens]**

The sankey traces the flow between agents and tools. Width represents volume. It's mostly just beautiful, but occasionally useful.

---

## SYNCHRONIZED SELECTION (0:44–0:48)

**[Synchronized selection]**

Click a node in the graph, it highlights in the lens. Click in the lens, it highlights in the graph. Everything stays in sync.

---

## REMOTE APPROVAL — DESKTOP (0:48–0:53)

**[Remote approval]**

When Claude needs permission, the request shows up as a card with a countdown. Approve or deny from right here — no terminal switching. No termnial needed.

---

## REMOTE APPROVAL — MOBILE (0:53–0:56)

**[Works on your phone]**

Same thing from your phone. Start a job at your desk, approve from the couch. The dashboard is fully responsive.

---

## MOBILE VIEWS (0:56–0:60)

**[Mobile graph + lenses]**

The full graph, all the lenses — everything works on mobile. Not a stripped-down version. The real thing.

## NOTES

- Total: ~65 seconds
- Keep the voiceover unhurried — you're showing something that speaks for itself
- If a section feels rushed, cut a word, don't speed up
- The footage should breathe — let the graph animate for a beat before talking over it
- Record in one take if possible, edit out pauses. Natural > polished.
