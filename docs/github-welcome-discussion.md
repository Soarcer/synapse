# Welcome to Synapse

Synapse is a real-time observability dashboard for Claude Code. If you've used it, tried to use it, or just watched the demo and have thoughts — this is the place.

## What I'd love to hear

- What worked, what didn't
- Features you wish existed
- Rough edges you hit during setup
- How you're using Claude Code and what visibility you're missing

## Current status

- Synapse is live on [npm](https://www.npmjs.com/package/@synapse-ai/cli)
- Source code is coming — I didn't want to delay the release again
- The [website](https://usesynapse.dev) has screenshots, a demo video, and install instructions

No question is too small. If something confused you for even 30 seconds, that's worth mentioning.
